# Medix — Programări Medicale Online

Medix este un concept de platformă online care simplifică programările la medic în România. Ideea a pornit de la frustrarea cu care ne confruntăm cu toții: telefoane la care nu răspunde nimeni, liste de așteptare lungi și lipsa transparenței în sistemul medical privat.

## Demo
https://valitevede.github.io/medix

## Ce face aplicația

Pacienții pot căuta un medic după specializare și oraș, pot vedea recenzii ale altor pacienți și pot face o programare direct din platformă. Medicii și clinicile au un cont separat prin care își pot gestiona programările primite.

Pe lângă asta, am integrat un chatbot simplu care răspunde la întrebări de bază și o hartă cu clinicile partenere.

## Tehnologii

HTML, CSS, JavaScript 

## Cum îl rulezi local

```bash
git clone https://github.com/valitevede/medix.git
```

Deschizi `index.html` în browser sau cu Live Server în VS Code.

## Status

Proiectul e în lucru. Următorii pași sunt un backend real pentru gestionarea conturilor și a programărilor, și o aplicație mobilă pentru Android și iOS. Este un proiect la care lucrez de mult timp si mi se pare ca este o problema reala in Romania acest domeniu.
